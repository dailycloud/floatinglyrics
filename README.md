# Floating Lyrics

Виджет с текстом песни, который живёт прямо на рабочем столе Windows: поверх обоев, под всеми окнами.
При наведении под текстом появляется «жидкое стекло», как в iOS, и меню настроек.

- синхронизированные тексты, пословная подсветка (Spicy Lyrics), бэк-вокал и дуэты;
- таймер на длинных проигрышах, визуализатор во время инструментала;
- свои шрифты (из установленных или из файла), режимы контраста для светлых обоев;
- Spotify и любые плееры, которые видит Windows (SMTC);
- обновляется сам.

## Установка

1. Скачайте **[FloatingLyrics-win-x64.zip](https://github.com/dailycloud/floatinglyrics/releases/latest/download/FloatingLyrics-win-x64.zip)**
   (или со страницы [Releases](https://github.com/dailycloud/floatinglyrics/releases/latest)).
2. Распакуйте в любую папку, например `%LOCALAPPDATA%\FloatingLyrics\app`, и запустите `FloatingLyrics.exe`.
   Ничего доустанавливать не нужно.
3. Наведите на виджет → шестерёнка → «Виджет» → «Запуск вместе с Windows».

Требуется Windows 10 1809+ или Windows 11 (x64). Новые версии виджет скачивает и ставит сам,
настройки при этом сохраняются.

## Планы

- [ ] **Живое стекло на Wallpaper Engine.** Сейчас под стеклом статичный снимок, а анимированные
      обои продолжают двигаться. Нужно сделать виджет отдельным окном над рабочим столом и брать
      картинку под стеклом через захват экрана в реальном времени.
- [ ] **Пословная подсветка у всех.** Встроить клиентский ключ Spicy Lyrics, чтобы она работала
      сразу после установки, без своего ключа.
- [ ] **Больше кастомизации:**
  - [ ] темы и пресеты оформления (сохранить, переключить, поделиться);
  - [ ] настройка визуализатора: стиль, цвета, высота;
  - [ ] свои цвета для активной строки, бэк-вокала и дуэтов;
  - [ ] размер и количество видимых строк, межстрочный интервал;
  - [ ] несколько мониторов: выбор, на каком показывать виджет.
- [ ] **Баги:**
  - [ ] иногда трек или текст в Spotify меняется с задержкой;
  - [ ] на очень светлых или пёстрых обоях текст бывает плохо видно;
  - [ ] после перезапуска Проводника виджет иногда пропадает до следующей проверки;
  - [ ] уменьшить размер пакета (сейчас около 120 МБ, обновление скачивается целиком).

Нашли баг или есть идея — пишите в [Issues](https://github.com/dailycloud/floatinglyrics/issues).

Подробности для разработчиков — в [FloatingLyrics/README.md](FloatingLyrics/README.md).
